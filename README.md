# Интернет-магазин питомника — демонстрационная версия

Статический многостраничный сайт (HTML, CSS, JavaScript). Все изображения хранятся локально в `assets/`. Сборка и серверная часть не требуются.

## GitHub Pages

1. Создайте публичный репозиторий `garden-nursery` (или выберите другой).
2. Загрузите содержимое этого архива **в корень** ветки `main`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. После успешной публикации GitHub покажет URL сайта в Settings → Pages.

## Ограничения

Бренд, цены, характеристики и изображения демонстрационные. Формы не отправляют данные, оплаты и серверной части нет. Корзина и избранное используют localStorage. Не вводите персональные данные для тестирования.

## QA

Chromium: проверены 10 страниц на ширинах 320, 390, 768, 1440 px, изображения, поиск и фильтрация, сортировка, корзина, избранное, варианты, пустые состояния, тестовое оформление заказа, мобильное меню. Проверка проводилась во встроенном режиме с эмуляцией хранилища; реальный HTTP-доступ в тестовой среде ограничен, GitHub Pages ещё не опубликован.
