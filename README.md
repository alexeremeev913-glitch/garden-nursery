# Хвойный сад

Статический сайт питомника в Мытищах. Для запуска откройте сайт через любой статический HTTP-сервер. GitHub Pages публикует корень ветки `main`.

Каталог, корзина и заявка в WhatsApp используют варианты из опубликованного прайса питомника за 2025 год. Данные каталога и ссылки на оригиналы фотографий находятся в `nursery-data.js`, скачиваемые прайсы — в `assets/price-2025.xlsx` и `assets/price-2025.csv`. Каждая строка соответствует одному варианту растения. У бальзамина цена в источнике отсутствует.

Корзина и избранное сохраняются в браузере. При оформлении посетитель переходит в WhatsApp с подготовленным списком и самостоятельно отправляет сообщение. Менеджер подтверждает наличие, актуальные цены, доставку и оплату.

Источник ассортимента и контактов — [сайт питомника](https://hvoynyisad.ru/).

Для коры анимированной сосны использован материал [Pine Bark от Poly Haven](https://polyhaven.com/a/pine_bark) (CC0).
